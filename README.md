# ZEPHYRIA

> Dans un monde où la terre a sombré sous un océan de nuages toxiques — Le Voile — l'humanité survit sur des îles flottantes. Nael, jeune Veilleur des Vents, découvre que les îles sombrent lentement et doit plonger dans les profondeurs interdites pour sauver ce qui reste du ciel.
